# FB Auto Poster Pro Product Site

Static bilingual marketing website for FB Auto Poster Pro.

## Preview

Run any static web server from this directory, for example:

```powershell
npx serve . -l 4173
```

## Configuration

Update `SITE_CONFIG.whatsappNumber` at the top of `app.js` when the sales WhatsApp number changes.

Pricing is intentionally shown as "Price on request" until final public prices and the exact trial period are confirmed.
